# Ratman client lib

This is the client library used to write applications for Ratman.  Currently only a [Rust](https://rust-lang.org) implementation exists.  The raw protocol is documented in the next chapter.

You can find `ratman-client` on [crates.io](https://crates.io/crates/ratman-client) and its documentation on [docs.rs](https://docs.rs/ratman-client)!

In addition to these following pages we recommend you read the  [Ratman Internals](./internals/index.md) page to get a better understanding of how Irdest works.
